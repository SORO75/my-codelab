# Python Installation on Linux

## Check if Python is already installed
python3 --version

## Install Python using apt (Debian/Ubuntu)
sudo apt update
sudo apt install python3 python3-pip

## Install Python using yum (CentOS/RHEL)
sudo yum install python3

## Install Python using dnf (Fedora)
sudo dnf install python3

## Verify installation
python3 --version
pip3 --version

## Set python3 as default python (optional)
sudo update-alternatives --install /usr/bin/python python /usr/bin/python3 1

the PEP8 Python style guide can be found at: https://www.python.org/dev/peps/pep-0008/
important points:
- Follow naming conventions (e.g., use lowercase with underscores for variable names)
- Keep line length to a maximum of 79 characters
- Use 4 spaces per indentation level
- Include docstrings for all public modules, functions, and classes
- Python files should be encoded in UTF-8
- Use absolute imports for clarity
- Avoid using wildcard imports (e.g., from module import *)
- Use parentheses for multi-line statements
- Write each statement on a new line
- Function, variable and file names should be lowercase,
     with words separated by underscores as necessary to improve readability
- Variable names should be descriptive and not overly abbreviated
- Constants should be defined at the top of the file and written in all capital letters
- Class names should use the CapWords convention (e.g., MyClass)
